# Ejemplo de documentación

Este archivo es un ejemplo pequeño de cómo se ve un Markdown dentro del repositorio.

## ¿Qué puedes ver aquí?

- Títulos con `#` y `##`
- Listas con viñetas
- Código en línea como `npx playwright test`

```bash
npx playwright test tests/clase-02/ --project=chromium
```

## Nota

Puedes crear más archivos dentro de `docs/` para cada clase, por ejemplo:

- `docs/clase-01.md`
- `docs/clase-02.md`
- `docs/clase-03.md`
